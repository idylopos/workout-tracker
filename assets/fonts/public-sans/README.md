# Public Sans

Unmodified regular and bold WOFF2 files from [USWDS Public Sans](https://github.com/uswds/public-sans/tree/develop/fonts/webfonts), retrieved 2026-09-16. These are static files, not the experimental variable fonts.

Bundled for the Progress interface, served locally with the app. No third-party font request is made at runtime. Font source is no longer actively maintained; pinned binary assets do not require runtime updates. See LICENSE.md and OFL.txt for redistribution terms and copyright notices.
